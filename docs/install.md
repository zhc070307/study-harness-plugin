# 下载和安装

返回[用户指南](../README.md)。从下载安装包开始，到在 Harness 中使用学习助手。

## 1. 下载插件

点击[下载插件安装包（0.1.2）](https://github.com/zhc070307/study-harness-plugin/raw/refs/heads/main/downloads/study-agent-harness-plugin-0.1.2.tgz)，保存到电脑的“下载”文件夹。

这是已经构建好的插件包，无需下载源码或自行编译。保留 `.tgz` 压缩包，安装时直接使用它。

仓库是私有仓库，下载需要在浏览器登录有访问权限的 GitHub 账号。链接显示 404 时，先确认登录和仓库访问权限；也可以在仓库的 `downloads` 文件夹中打开安装包页面，点击 **Download raw file**。

这个版本支持 Harness **0.2.0-rc.2** 和 **0.2.1-alpha.2**。默认更新渠道当前提供 `0.2.0-rc.2`，不需要为了安装插件切换到实验版。其他 Harness 版本仍需验证兼容性。

## 2. 装进 Harness

### 桌面版

1. 打开 Harness，进入侧栏的 **插件** 页面。
2. 点击 **添加插件**，填入下载的 `.tgz` 文件的**完整路径**。
3. 点击 **安装**，等待完成，确认插件开关已启用。
4. 重启 Harness。

路径示例（把“你的用户名”换成实际用户名）：

- macOS：`/Users/你的用户名/Downloads/study-agent-harness-plugin-0.1.2.tgz`
- Windows：`C:/Users/你的用户名/Downloads/study-agent-harness-plugin-0.1.2.tgz`

输入框里只填路径，不加引号。安装需要联网获取依赖。如果之前安装了旧版，请先在插件页卸载旧包，再安装 0.1.2；项目里的学习记录会保留。

### 网页版

在运行 Harness 的电脑上下载插件包，再运行下面的命令，将路径换成实际路径：

```sh
dsh plugin --profile web add "/完整路径/study-agent-harness-plugin-0.1.2.tgz"
```

使用自定义配置时，将 `web` 换成对应的名称。远程服务器上运行的 Harness，需要把包放在服务器上。

桌面版优先用窗口安装。使用命令管理桌面插件时，先通过应用菜单的 **管理 dsh 命令…** 安装桌面自带命令；启动一次桌面版后完全退出，再运行 `dsh plugin --profile desktop add "安装包完整路径"`。通过 npm 安装的 `dsh` 命令不能管理桌面插件。

## 3. 开始使用，依赖会自动检查

打开准备存放课程材料的项目，向助手发送：

> 把这个项目绑定为学习项目，检查学习插件的依赖，缺少的就安装，然后查看课程记录。

插件会使用 Harness 自带的 Python，检查已有依赖，只安装缺少的包。桌面版用户不需要另建 Python 环境，也不需要手填解释器路径。网络正常时，首次准备完成后就可以直接使用。

确认助手返回课程记录后，上传一份讲义，再说：

> 导入这份讲义，读一下内容，告诉我主要讲什么。

能导入并读取材料，就说明基础功能可以使用了。新项目没有课程是正常的；同一项目下新开的对话会自动获得学习工具。

Harness 如请求本次工具执行权限，按操作需要授权。需要查看环境状态或重试时，可以说：

> 检查学习插件现在用的 Python 和依赖。上次缺少的包如果还没装好，请重试。

Web 或自定义宿主没有内置 Python 时，插件会尝试使用已有的系统 Python（3.10+）。电脑上连 Python 解释器也没有时，需要先提供解释器；插件只补装自己的依赖。录音转写需要 Python 3.12。

如果你之前手动指定过 Python，插件会尊重已有配置。想改回 Harness 自带环境时，将该插件配置里的 `python` 改为 `auto`，然后重启；新安装无需修改配置。

## 可选功能

- **生成 PDF 笔记或练习：** 需要额外安装 LaTeX，并确保 `latexmk` 和 `xelatex` 可运行。读取已有 PDF 材料不需要 LaTeX。
- **录音转写：** 可以先让助手检查 GPU 和空间是否足够。首次下载约 3.8 GiB 模型会另外征求同意，依赖检查不会下载模型。
- **日历：** Apple Calendar 和 CalDAV 都需要单独接入，见[日历配置](setup.md#外部日历)。不连接日历也可以使用学习功能。

## 如果没有成功

| 现象 | 可以先检查什么 |
| --- | --- |
| 下载显示 404 | GitHub 是否登录了有权访问这个私有仓库的账号。 |
| 找不到安装文件 | 输入的是安装包实际完整路径，而不是示例用户名或解压目录。 |
| 插件已安装，但没有学习工具 | 插件是否启用、Harness 是否重启、当前项目是否绑定。 |
| 依赖安装失败 | 让助手报告实际缺失项；检查网络或环境写入权限后再重试。 |
| 提示版本不兼容 | 是否下载了新版 0.1.2，以及 Harness 是否为上述支持版本。 |
| 提示 `failed to import` | 插件模块加载失败，需要查看具体错误；这一步还没有开始准备 Python 依赖。 |
| 提示 `ERR_PNPM_GIT_DEP_PREPARE_NOT_ALLOWED` | 正在安装旧版源码；改用上面的 0.1.2 安装包。无需修改 `allowBuilds`。 |

反馈问题时，提供操作系统、Harness 版本和实际错误提示。

如果桌面版只显示 `failed to import`，请下载[桌面诊断脚本](https://github.com/zhc070307/study-harness-plugin/raw/refs/heads/main/scripts/diagnose-desktop.command)，保存到下载文件夹，然后在终端运行：

```sh
bash "$HOME/Downloads/diagnose-desktop.command"
```

脚本用桌面应用自带的 Electron 和实际插件配置检查导入，不执行学习工具，不安装依赖，不修改配置。请复制终端中的完整输出。应用需要位于 `/Applications` 或个人 `Applications` 文件夹。

Harness 禁止通过 `dsh --profile desktop --dump-config-schema` 检查保留的桌面配置，即使使用桌面自带的命令也一样；请使用上述脚本。

如果脚本显示“插件模块导入成功”，但窗口仍提示加载失败，先完全退出 Harness 再重新打开：macOS 使用 **⌘Q**，只关闭窗口不算退出。Harness 替换已安装的插件时会要求重启；插件页显示新版并不代表运行中的宿主已经加载新版。重新打开后确认插件启用，再尝试绑定学习项目。
