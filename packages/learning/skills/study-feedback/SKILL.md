# 作答与反馈

根据课程目标、已讲范围、可用题源和用户要求选择练习形式。自组卷采用 [学习练习规范](../study-worksheets/SKILL.md)，笔记采用 [学习笔记规范](../study-notes/SKILL.md)；是否使用这些形式、题量、语言和节奏由当前要求与课程约定决定，不跨课程强行套用。

先查原题、来源与既有练习，核对题目条件和答案。题面完整，正式作答前不泄露答案或解法提示；不虚构考试难度或固定达标分数。已有未作答题继续使用，除非用户要求修订。概念选择题、计算、证明和建模等各有不同用途，不将一种形式当成所有能力的证据。

收到真实作答后，保存原答案、来源、批改说明、有效评分和用户表达的不确定处。题目本身含糊或错误时先修正或排除，不登记为用户薄弱点。提问、未知、未作答和需要解释，都不等于错误；不猜测错因。

具体错点、猜测或不稳定表现保存到课程的作答与发现记录。再次出现同一问题时追加实际证据，不覆盖第一次记录或重复创建错点。复测关联原问题和新的独立作答；通过后仍保留原错误，后续失败或不确定如实更新。一次正确只证明这次表现，讲解或交付不能证明掌握。

按用户要求和已议定的方法安排后续：可复用已有任务、在合适条件下复测或说明暂缓原因。没有授权时不因发现错点自动增加一批学习任务；已经约定的常规后续无需反复确认。结束前读回本次保存的作答与发现，确认没有只写进聊天或任务描述而漏掉实际记录。

## 保存和读回

先用 `study_read` 读取本课程已存在的作答、发现和任务；记录时使用工具返回的实际处理步骤和字段。原答案、题目来源、批改说明、评分与不确定标记一同保留，不将新反馈覆盖在旧证据上。保存后读回本次记录，确认对应的是正确课程、题目和用户作答；失败时报告未保存范围。

任务描述只留剩余行动、材料位置与完成标准，具体诊断和原答案在作答记录中保存。用户只要求解释时可以直接解释，不制造作答、评分或任务。
