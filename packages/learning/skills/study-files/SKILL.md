# 课程与材料

先阅读内容，再判断材料的用途、课程归属、授课范围与关联。文件名、扩展名、上传时间、日历结束和文件夹位置都不能证明讲授内容、出勤、阅读或掌握。文字提取不完整时，查看实际 PDF 页面；图片能力不可用时明确说明限制。

原件和来源保留。用 `publish` 将明确归属的文件关联到课程的相对路径，记录依据；移动、重命名和改写使用当前版本，遇到冲突保留双方内容。录音、转写和课件只有内容或明确说明能证明关系时才一起处理，不按日期机械捆绑。无需新笔记时可以复用既有成果并说明原因，不为关闭材料事件制作假文件。

`COURSE.md` 保存课程目标、材料地图、正式要求、已议定的方法、当前教学范围、实际学习状态和等待条件，不写成操作流水账或重复任务清单。修改前保留快照；相关事实改变后，核对课程说明、任务和证据是否一致。版本核对只能证明对应版本经过检查，不能代替内容判断。文件移动后同步课程和任务引用，避免把迁移误当新材料。

桌面提供课程入口和新文件的待整理区域，课程内再按用途设分类文件夹。用户新文件先落在桌面；助理读取后结合用户说明归类，不要求用户先选目标文件夹。生成的笔记、练习和 PDF 必须位于相应课程的分类之下；无法确定课程时先核对来源，不把成果丢进桌面或未整理。已有分类和用户命名优先，不为每次生成另建桌面根文件夹。

课程文件按用途组织：笔记放 notes，课程来源放 materials，练习放 practice，正式作业放 assignments；已有结构或用户指定方式优先。不要为日期、每次操作或新经验不断增建目录和规则文件。处理材料事件后保存真实回执：读了什么、范围如何确认、复用了什么、任务有哪些变化，或为什么无需任务。尚未处理的范围保持未完成。

## 操作入口

先用 `study_desktop list/read` 获取文件身份、实际内容和版本；确实需要课程时用 `course` 建立入口，再 `publish` 关联明确材料。移动或重命名用 `metadata`，改写用 `write`，移除和恢复用 `remove_file/restore_file`，都使用当前版本。用户未要求时不改写原件，不将上传或移动解释为学习完成。

文件内容需要变成笔记或练习时分别读取对应规范。已有讲稿或转写稿直接读取；只有用户需要识别录音时才读取录音转写规范，不要求先安装转写。

## 教材定位

教材保留原 PDF，课程材料地图记录实际名称、版本、用途和来源优先级。处理长教材时使用 `study_textbook`，不以整本 PDF 的截断文字代替完整检索，也不要求用户反复上传已保存的习题页。

先 `status(file)`；没有当前版本索引时，使用实际文件哈希 `index(file, expected)` 按页建立全文索引。根据实际标题页、目录和原页核对教材名称、版本、章节范围与纸书/PDF 页码对应，再更新 `title`、`edition`、`chapters` 和 `page_map`；同版本更新映射复用页文字。映射未知时留空，不猜固定页码差，不把章节索引当成已讲或已掌握的范围。不同教材与版本分别处理，不写死课程、书名或关键词。

按问题语境选择教材中的实际关键词；英文教材的中文问题由你转换为相关英文术语，必要时尝试不同表述，不声称具有自动语义检索。`search` 可结合章节、纸书页码或 PDF 页码范围，返回版本、候选页、片段和来源；结果多时用 `next_offset` 继续。未命中不能证明教材中没有内容，也不能据此编造原题。

定位后用 `read(file, pdf_page, expected)` 读取原页提取的文字；长页按 `next_offset` 继续。涉及公式、图形、复杂排版或文字提取不全时，用 `study_desktop page(file, page, expected)` 查看原 PDF。读取实际题目、小问及相邻必要条件后才能选用。无图像能力时如实说明，不能声称完成原页视觉核验。

没有可提取文字的页保留原页与明确提示，当前不自动 OCR。用户替换教材后重新建立当前版本索引；旧映射不自动套用。文件移除后停止检索，恢复后可复用原版本索引。索引与映射随学期备份保存，恢复后按当前文件身份读取，不依赖旧电脑的绝对路径。
